## 💡 فلسفه بنیادین: شواهد واقعی به جای محبوبیت کاذب

> **اسکیل منیجر (Skill Manager) یک مخزن مهارت استاتیک نیست. این پروژه یک لایه زیرساختی برای ایجنت‌های هوش مصنوعی خودمختار (Autonomous AI Agents) است.**

مخازن سنتی مهارت‌ها مانند فروشگاه‌های فایل متنی استاتیک عمل می‌کنند:
> *«این لیست ۵۰۰ فایل مارک‌داون است. بین آن‌ها جستجو کنید، ستاره بدهید یا ۵۰ مهارت را همزمان نصب کنید.»*

**این ساختار برای ایجنت‌های هوشمند کاملاً ناکارآمد است.** ایجنت‌ها نیازی به ستاره‌های گیت‌هاب، فایل‌های حجیم و نامطمئن یا اشغال کردن پنجره کانتکست ندارند.

### تغییر پارادایم در تفکر ایجنت

هنگامی که یک ایجنت خودمختار با یک تسک مهندسی مواجه می‌شود، این‌گونه فکر نمی‌کند:
> ❌ *«اجازه دهید در فولدری با ۵۰ مهارت جستجو کنم تا ببینم چه چیزی ممکن است مناسب باشد.»*

بلکه ایجنت این‌گونه فکر و عمل می‌کند:
> 🧠 **«من در حال دیباگ یک مشکل شبکه‌ای در زبان Rust هستم. بالاترین رتبه و اثبات‌شده‌ترین گردش‌کار دیباگ Rust را که روی پروژه‌های مشابه جواب داده است برای من استخراج کن.»**

```
               مخازن سنتی مهارت‌ها در برابر اسکیل منیجر
┌───────────────────────────────────────┐   ┌──────────────────────────────────────────┐
│             مخازن سنتی               │   │              اسکیل منیجر                 │
├───────────────────────────────────────┤   ├──────────────────────────────────────────┤
│ • رتبه‌بندی بر اساس ستاره و محبوبیت  │   │ • دفتر کل شواهد و نتایج تجربی واقعی     │
│ • کپی-پیست متن‌های استاتیک           │   │ • موتور رتبه‌بندی پویا بر اساس تسک و پروژه│
│ • نصب فله‌ای و حجیم ده‌ها مهارت      │   │ • تزریق سبک و بلادرنگ در کسری از ثانیه   │
│ • دستورالعمل‌های تست‌نشده و ایستا    │   │ • خط لوله ادغام تکاملی ۷ مرحله‌ای       │

```

## 📊 دفتر کل شواهد تجربی و بازخورد پروژه‌های واقعی

مهارت‌ها در اسکیل منیجر بر اساس نتایج واقعی اجرای تسک‌ها روی پروژه‌های زنده رتبه‌بندی و بنچمارک می‌شوند. هر اجرای ایجنت یک رکورد شواهد ثبت می‌کند:

<div align="center" dir="ltr">

```yaml
Repository:    "Rust compiler plugin"
Task:          "Fix CI async deadlock in worker channels"
Outcome:       ✅ Success
Time (MTTR):   3 min (180s)
Model:         GPT-5
Cost:          $0.19
Tokens:        14,500
Skill Version: v4.1.0
Evidence Note: "Resolved non-blocking tokio task channels and updated lifetime bounds."
```

</div>

زمانی که ایجنت دیگری با تسک مشابهی روبرو شود، اسکیل منیجر با تحلیل تطابق معنایی، نرخ موفقیت اثبات‌شده، زمان حل مسئله (MTTR) و عملکرد مدل، بهترین و مطمئن‌ترین مهارت را بازمی‌گرداند.

## 🚀 راهنمای سریع برای ایجنت‌ها و توسعه‌دهندگان

### ۱. نصب ابزار خط فرمان (`eshkill` / `askill`)
```bash
git clone https://github.com/shatinz/skill-manager.git
cd skill-manager
pip install -e ./cli
```

### ۲. استخراج هوشمند و رتبه‌بندی تسک‌محور مهارت (`rank`)
به جای جستجوی دستی، اثبات‌شده‌ترین مهارت را برای تسک خود فراخوانی کنید:

```bash
eshkill rank --task "Fix CI" --repo "Rust compiler plugin" --model "GPT-5"
```

### ۳. ثبت شواهد و تله‌متری اجرا (`report-evidence`)
```bash
eshkill report-evidence \
  --skill rust-axum-tokio-async \
  --repo "Rust compiler plugin" \
  --task "Fix CI" \
  --outcome success \
  --duration 180 \
  --model "GPT-5" \
  --cost 0.19 \
  --version "4.1.0" \
  --notes "Resolved non-blocking tokio task channels"
```

### ۴. خود-ترمیمی و ارسال خودکار پروپوزال ایجنت (`auto-propose`)
هنگامی که ایجنت با خطای زمان اجرا، تغییر کتابخانه‌ها یا اخطار کامپایلر مواجه می‌شود، مستقیماً با برچسب مشخص `🤖 Autonomous Agent` پیشنهاد اصلاحی ارسال می‌کند:

```bash
eshkill auto-propose \
  --skill fastapi-production-craft \
  --feedback "DeprecationWarning: Starlette 0.40 form parsing changed" \
  --fix "Enforce async request.form() with python-multipart>=0.0.20" \
  --reason "Resolve Starlette async form deprecation" \
  --agent-id "agent:autonomous-debugger" \
  --model "claude-3-5-sonnet"
```

## 🔌 یکپارچه‌سازی با پروتکل کانتکست مدل (MCP)

اسکیل منیجر به صورت نیتیو از استاندارد Model Context Protocol (MCP) بر بستر stdio و SSE پشتیبانی می‌کند و با **Claude Desktop**، **Cursor**، **Windsurf** و **Antigravity** هماهنگ است:

```json
{
  "mcpServers": {
    "skill-manager": {
      "command": "python",
      "args": ["-m", "eshkill.cli", "mcp"],
      "env": {
        "SKILL_MANAGER_API_URL": "http://127.0.0.1:8000/api"
      }
    }
  }
}
```

## 🏛️ مخزن زنده مهارت‌ها (۶۰ مهارت عملیاتی)

| دسته‌بندی | توضیحات و الگوهای کلیدی |
| :--- | :--- |
| **🤖 ایجنت‌ها و هوش مصنوعی** | سرور FastMCP، حافظه گراف دانش، استدلال ترتیبی (Tree-of-Thought)، تیم‌های چند ایجنتی LangGraph، جستجوی هیبریدی RAG. |
| **🌐 فریم‌ورک‌های وب** | نکست‌جی‌اس ۱۵ (App Router)، تن‌استک روتر و کوئری، ری‌اکت ۱۹، فست‌اِی‌پی‌آی، هونو اج کلودفلر، استرو ۵. |
| **🎨 طراحی رابط کاربری** | شادسن و توکن‌های تیل‌ویند، گرادینت‌های محیطی دارک‌مود، چیدمان واکنش‌گرای سیال، دسترس‌پذیری WCAG. |
| **🗄️ دیتابیس‌ها و ذخیره‌سازی** | بهینه‌سازی کوئری‌های پستگرس با Explain Analyze، سوپابیس RLS، پریسما ORM، دریزل، داک‌دی‌بی و پولارز. |
| **☁️ دوآپس و ابری** | گیت‌اوپس با ArgoCD و هلم، داکر Distroless چندمرحله‌ای، ماتریس گیت‌هاب اکشنز، اوپن‌تله‌متری و پرومتئوس. |
| **🛡️ امنیت و تست SAST** | اسکنر OWASP Top 10، جلوگیری از نشت کلیدها، امنیت احراز هویت JWT/OAuth2، پیشگیری از XSS. |
| **🧪 تست و تضمین کیفیت** | ماک و فیکسچرهای Pytest، اتوماسیون تست E2E با Playwright، تست مبتنی بر ویژگی Hypothesis. |
| **📈 تجارت الکترونیک و بیزینس** | وب‌هوک‌های استرایپ، سیستم چندارزی، تولید متاتگ‌های سئو، بهینه‌سازی قیف فروش. |
| **📐 معماری تمیز و سیستم‌ها** | وب‌سرویس‌های راست با Axum و Tokio، الگوی Outbox و Event Sourcing، اسناد تصمیم‌گیری معماری (ADR). |
